# Portfolio

Premium single-page developer portfolio built with React, Vite, Tailwind CSS, Framer Motion, and lucide-react.

## Quick start

```bash
npm install
npm run dev
```

## Content

All portfolio content lives in `src/data/`. Edit those files to add/remove projects, experience, skills, certifications, and achievements — no presentation changes required.

## Atmosphere preview

Use the **Atmosphere preview** panel (bottom-right) to test every weather × time-of-day combination. Time of day defaults to the local system clock.

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run preview` — preview production build
